链表 (Linked List)

基础

💡 什么是链表？

链表是一种线性数据结构，但与数组不同——它的元素在内存中不连续存储。每个节点包含数据和指向下一个节点的指针。就像一列火车，每节车厢独立存在，通过挂钩连接。插入删除只需改两个指针O(1)，但查找需要从头遍历 O(n)。

📖 数组模拟法 — 竞赛首选

竞赛中用数组模拟链表：e[idx]存数据，ne[idx]存下一节点的下标，head指向头节点。本质是把 Node* next 指针换成了 int ne[i] 下标。预分配数组，比 new/delete 快得多。

操作复杂度说明
头插法 addHead(x)O(1)新节点插入头部，更新 head
指定位置后插入O(1)已知节点位置，改两个指针即可
删除指定节点后一个O(1)跳过被删节点，改指针
遍历链表O(n)从 head 沿 ne 链走到底
查找元素O(n)无随机访问，只能顺序查找
C++
const int N = 1e5 + 5;
int head = -1, e[N], ne[N], idx = 0;
// head=-1 表示空链表
// idx 记录下一个可用的数组位置

// 头插法：在链表头部插入值为 x 的节点
void addHead(int x) {
    e[idx] = x;        // 存数据
    ne[idx] = head;    // 新节点指向原来的头
    head = idx++;      // head 指向新节点
}

// 在第 k 个插入的节点后面插入 x（k 从 0 开始）
void addAfter(int k, int x) {
    e[idx] = x;
    ne[idx] = ne[k];   // 新节点指向 k 的下一个
    ne[k] = idx++;     // k 指向新节点
}

// 删除第 k 个插入的节点后面的节点
void removeAfter(int k) {
    ne[k] = ne[ne[k]]; // 跳过 k 的下一个节点
}

// 遍历链表
for (int i = head; i != -1; i = ne[i])
    cout << e[i] << " ";

// 双向链表扩展：增加 l[N], r[N] 数组存左右邻居
🏆 竞赛口诀： 数组模拟链表 = 把 Node* next 换成 int ne[i]。初始化 head=-1 表示空链表。竞赛中极少用指针链表（慢、易出错），数组模拟是标准写法。

栈 (Stack)

基础

💡 什么是栈？

栈是一种后进先出 (LIFO) 的数据结构——就像一摞盘子，最后放的先拿走。只能从一端（栈顶）操作：push入栈、pop出栈、top看栈顶。函数调用、括号匹配、DFS 都用到栈。

📖 单调栈 — 核心应用

栈内元素保持单调性（递增或递减）。新元素入栈前，把破坏单调性的元素弹出——弹出时就找到了这些元素的答案。典型应用：找每个元素右边第一个比它大的值，O(n)。

操作复杂度说明
push(x)O(1)stk[++top] = x
pop()O(1)top--
top()O(1)返回 stk[top]
单调栈O(n)每个元素入栈出栈各一次
C++
const int N = 1e5 + 5;
int stk[N], tp = 0;  // tp=栈顶指针，0 表示空

void push(int x) { stk[++tp] = x; }  // 入栈
void pop() { tp--; }                  // 出栈
int top() { return stk[tp]; }         // 看栈顶
bool empty() { return tp == 0; }

// ===== 单调栈：找每个元素右边第一个更大值 =====
vector nextGreater(vector& a) {
    int n = a.size(); vector res(n, -1);
    int stk[N], tp = 0;
    for (int i = 0; i < n; i++) {
        // 当前元素比栈顶大 → 栈顶找到了答案
        while (tp && a[stk[tp]] < a[i])
            res[stk[tp--]] = i;  // 或 a[i]
        stk[++tp] = i;  // 下标入栈
    }
    return res;
}
// 单调解法思路：维护递减栈，新元素进来时，
// 所有比它小的栈内元素都找到了"右边第一个更大的"
🏆 竞赛技巧： 推荐用数组模拟栈而非 std::stack——能访问栈内任意元素，调试更方便，速度更快。单调栈每个元素入栈一次出栈一次=O(n)。

队列 (Queue)

基础

💡 什么是队列？

队列是一种先进先出 (FIFO) 的数据结构——就像排队，先来的先处理。队尾进 (push)，队头出 (pop)。BFS、任务调度都依赖队列。

📖 单调队列 — 滑动窗口神器

维护队列内单调性，队首是窗口最值。两步操作：①去过期（队首滑出窗口就弹出）；②保单调（新元素入队尾前，弹掉比它差的）。滑动窗口最值 O(n)。

操作复杂度说明
push(x)O(1)q[++tt] = x
pop()O(1)hh++
front() / back()O(1)队首 / 队尾
单调队列（滑动窗口）O(n)每个元素进出各一次
C++
const int N = 1e5 + 5;
int q[N], hh = 0, tt = -1;  // hh=队头, tt=队尾

void push(int x) { q[++tt] = x; }  // 入队
void pop() { hh++; }                // 出队
int front() { return q[hh]; }
bool empty() { return hh > tt; }

// ===== 单调队列：滑动窗口最小值 O(n) =====
vector slidingMin(vector& a, int k) {
    int q[N], hh = 0, tt = -1;  // 存下标
    vector res;
    for (int i = 0; i < a.size(); i++) {
        // 第1步：去过期 — 队首滑出窗口
        if (hh <= tt && q[hh] <= i - k) hh++;
        // 第2步：保单调 — 弹掉所有 ≥a[i] 的
        while (hh <= tt && a[q[tt]] >= a[i]) tt--;
        q[++tt] = i;  // 入队
        if (i >= k - 1) res.push_back(a[q[hh]]);
    }
    return res;
}
// 求最大值：把 >= 改成 <= 即可
🏆 单调队列两步走：①去过期（hh 右移）②保单调（tt 左移弹掉更差的）。队首永远是窗口内的最值。

二叉树 (Binary Tree)

基础

💡 什么是二叉树？

每个节点最多有两个子节点（左/右）。二叉树是所有树形结构的基础——堆、线段树、Trie、BST 都是它的变体。存储方式有链式（指针）和顺序存储（数组，i的左子=2i，右子=2i+1）。

📖 四种遍历

前序（根→左→右）：用于复制树。中序（左→根→右）：BST 有序输出。后序（左→右→根）：删除树。层序（BFS）：广度优先。已知中序+前序/后序可唯一确定一棵树。

操作复杂度说明
前序遍历O(n)根→左→右（递归/栈）
中序遍历O(n)左→根→右（BST 有序）
后序遍历O(n)左→右→根（删除用）
层序遍历O(n)BFS 队列实现
前序+中序构造树O(n)前序第一个是根，中序定位左右
C++
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

// 前序：根→左→右
void preorder(TreeNode* r) {
    if (!r) return;
    cout << r->val; preorder(r->left); preorder(r->right);
}
// 中序：左→根→右
void inorder(TreeNode* r) {
    if (!r) return;
    inorder(r->left); cout << r->val; inorder(r->right);
}
// 后序：左→右→根
void postorder(TreeNode* r) {
    if (!r) return;
    postorder(r->left); postorder(r->right); cout << r->val;
}

// 已知前序+中序，构造二叉树 O(n)
TreeNode* build(vector& pre, vector& in,
                int pl, int pr, int il, int ir) {
    if (pl > pr) return nullptr;
    int rootVal = pre[pl];  // 前序第一个 = 根
    // 在中序中找到根的位置
    int k = find(in.begin()+il, in.begin()+ir+1, rootVal) - in.begin();
    TreeNode* root = new TreeNode(rootVal);
    int leftSize = k - il;
    // 递归构造左右子树
    root->left  = build(pre, in, pl+1, pl+leftSize, il, k-1);
    root->right = build(pre, in, pl+leftSize+1, pr, k+1, ir);
    return root;
}
🏆 关键理解： 前序第一个=根；中序中根左边=左子树，右边=右子树。递归应用即得整棵树。前序+后序不能唯一确定（无法区分左右）。

堆 (Heap)

进阶

💡 什么是堆？

堆是一种完全二叉树，满足堆性质：每个节点 ≤ 子节点（小根堆）或 ≥ 子节点（大根堆）。数组存储，i 的左子=2i，右子=2i+1，父=i/2。取最值 O(1)，插入/删除 O(log n)。

📖 up 上浮 vs down 下沉

插入：新元素放末尾→与父节点比较→如果更小就交换（up 上浮）。删堆顶：最后元素搬到堆顶→与较小儿子比较→如果更大就交换（down 下沉）。每次交换上升/下沉一层，最多 log n 层。

操作复杂度说明
push(x) 插入O(log n)末尾插入 + up 上浮
pop() 删堆顶O(log n)最后元素替堆顶 + down 下沉
top() 取堆顶O(1)直接返回 heap[1]
build() 建堆O(n)从 n/2 到 1 逐个 down（比逐个插入 O(n log n) 更快）
C++
const int N = 1e5 + 5;
int heap[N], sz = 0;  // sz = 堆大小

// 上浮：从位置 u 向上调整（插入时用）
void up(int u) {
    while (u > 1 && heap[u] < heap[u >> 1]) {
        swap(heap[u], heap[u >> 1]);
        u >>= 1;  // u = u/2，跳到父节点
    }
}
// 下沉：从位置 u 向下调整（删除时用）
void down(int u) {
    int t = u;
    if (u*2 <= sz && heap[u*2] < heap[t]) t = u*2;
    if (u*2+1 <= sz && heap[u*2+1] < heap[t]) t = u*2+1;
    if (t != u) { swap(heap[u], heap[t]); down(t); }
}
void push(int x) { heap[++sz] = x; up(sz); }   // 插入
void pop() { heap[1] = heap[sz--]; down(1); }  // 删堆顶
int top() { return heap[1]; }                   // 取堆顶
// O(n) 建堆：从最后一个非叶节点开始逐个 down
void build() { for (int i = sz/2; i; i--) down(i); }

// 对顶堆：维护中位数
// 大根堆(左半) + 小根堆(右半)，平衡两堆大小
🏆 手写堆 vs STL： priority_queue 只能取堆顶，不能修改内部元素。手写堆可以修改任意位置并重新 up/down——Dijkstra 的惰性删除就可以用手写堆优化。

哈希表 (Hash Table)

进阶

💡 什么是哈希表？

把任意类型的数据映射到数组下标，实现 O(1) 均摊的增删查。核心挑战是冲突——不同数据可能映射到同一位置。两种处理方式：拉链法（每个槽挂链表）和开放寻址法（冲突时往后找空位）。

📖 为什么 N 要取质数？

如果 N=10，所有以 0 结尾的 key 都映射到同一位——分布不均。质数作为模数可以避免这种周期性冲突。常用质数：100003, 200003, 300007。开放寻址法需要 N 为数据量的 2~3 倍。

操作复杂度说明
插入 (开放寻址)O(1) 均摊找空位插入，冲突时线性探查
查找 (开放寻址)O(1) 均摊探查直到找到或遇空位
插入 (拉链法)O(1) 均摊头插法挂到对应槽的链表
字符串哈希O(n) 预处理 / O(1) 比较子串比较从 O(n) 变 O(1)
C++
// ===== 开放寻址法（推荐，缓存友好）=====
const int N = 200003;  // 质数，2~3 倍空间
const int INF = 0x3f3f3f3f;
int h[N];
memset(h, 0x3f, sizeof h);  // 初始化为 INF 表示空

// find：找到 x 应该存的位置（或已存的位置）
int find(int x) {
    int k = (x % N + N) % N;  // 处理负数取模
    while (h[k] != INF && h[k] != x) {
        k++;           // 线性探查
        if (k == N) k = 0;  // 循环
    }
    return k;
}
void insert(int x) { h[find(x)] = x; }
bool contains(int x) { return h[find(x)] == x; }

// ===== 字符串哈希：O(1) 比较任意子串 =====
typedef unsigned long long ull;
const ull BASE = 131;  // 131 或 13331
ull hsh[N], p[N];
void init(string& s) {
    int n = s.size(); p[0] = 1;
    for (int i = 0; i < n; i++) {
        hsh[i+1] = hsh[i] * BASE + s[i];
        p[i+1] = p[i] * BASE;
    }
}
ull getHash(int l, int r) {  // [l, r] 的哈希值
    return hsh[r+1] - hsh[l] * p[r-l+1];
}
🏆 选择建议： 日常刷题用 unordered_map（加防卡哈希）；手写时用开放寻址法（比拉链法更快）。字符串哈希简单实用，应优先掌握。

并查集 (DSU)

核心

💡 什么是并查集？

处理集合合并与查询的数据结构。"A和B在同一集合吗？""把这两个集合合并"。每个元素指向父节点，根节点代表整个集合。合并时只需把一棵树的根指向另一棵。

📖 路径压缩 + 按秩合并

路径压缩：find 时把路径上所有节点直连到根，以后查找 O(1)。按秩合并：小树并入大树，保持树高 O(log n)。双优化后均摊 ≈O(α(n))≈O(4)≈常数！

操作复杂度说明
find(x)O(α(n)) ≈ O(1)找根 + 路径压缩
unite(x,y)O(α(n)) ≈ O(1)合并两集合，按秩合并
same(x,y)O(α(n)) ≈ O(1)判断是否同集合
扩展域 / 带权 DSUO(α(n))处理对立关系 / 维护距离
C++
struct DSU {
    vector fa, sz;
    DSU(int n) : fa(n + 1), sz(n + 1, 1) {
        iota(fa.begin(), fa.end(), 0);  // 初始：每个元素独立
    }
    int find(int x) {
        // 路径压缩：找到根后顺手把路径上所有节点直连根
        return fa[x] == x ? x : fa[x] = find(fa[x]);
    }
    bool unite(int x, int y) {
        x = find(x), y = find(y);
        if (x == y) return false;  // 已在同集合
        if (sz[x] < sz[y]) swap(x, y);  // 小树并入大树
        fa[y] = x; sz[x] += sz[y];
        return true;
    }
    bool same(int x, int y) { return find(x) == find(y); }
    int size(int x) { return sz[find(x)]; }
};

// 扩展域（种类并查集）：x 和 x+n 表示对立关系
// DSU dsu(2*n); dsu.unite(x, y+n); 表示 x 和 y 是敌人
🏆 核心理解： find 里的 fa[x]=find(fa[x]) 既是递归找根又是路径压缩，是并查集的灵魂。Kruskal 最小生成树、连通性判断都依赖它。

树状数组 (BIT)

进阶

💡 为什么需要树状数组？

数组：单点修改 O(1) 但区间和 O(n)。前缀和：区间和 O(1) 但单点修改 O(n)。树状数组两者都是 O(log n)！代码不到 10 行，是最简洁的区间查询结构。核心是 lowbit。

📖 lowbit 原理

lowbit(x) = x & -x 取出 x 的最低位 1。tr[x] 管理 a[x-lowbit(x)+1 .. x] 这个区间。add：沿 lowbit 往上跳更新所有包含 x 的区间。sum：沿 lowbit 往下跳累加前缀和。

操作复杂度说明
add(x, c)O(log n)a[x] += c，沿 lowbit 往上更新
sum(x)O(log n)查前缀和 a[1..x]，沿 lowbit 往下
rangeSum(l,r)O(log n)sum(r) - sum(l-1)
差分 BITO(log n)区间加 + 单点查
C++
const int N = 1e5 + 5;
int tr[N], n;  // 树状数组，1-indexed

int lowbit(int x) { return x & -x; }  // 取最低位1

// 单点修改：a[x] += c，向上更新
void add(int x, int c) {
    for (int i = x; i <= n; i += lowbit(i))
        tr[i] += c;
}
// 前缀查询：a[1] + a[2] + ... + a[x]
int sum(int x) {
    int res = 0;
    for (int i = x; i; i -= lowbit(i))
        res += tr[i];
    return res;
}
int rangeSum(int l, int r) { return sum(r) - sum(l - 1); }

// ===== 差分 BIT：区间加 + 单点查 =====
// add(l, x); add(r+1, -x);  查x的值：sum(x)

// 核心图解：
// sum(7): 7→6→4→0 (每次减 lowbit，O(log n)步)
// add(3): 3→4→8→... (每次加 lowbit，O(log n)步)
🏆 口诀： sum 往下跳（减 lowbit），add 往上跳（加 lowbit）。BIT 是线段树的轻量替代——能用 BIT 的场合优先用 BIT。

线段树 (Segment Tree)

高级

💡 为什么需要线段树？

BIT 只能做前缀和类操作。线段树支持区间修改 + 任意区间查询（和、最值、GCD 等）。核心是懒标记 (Lazy Tag)：修改时不递归到底，只在节点上"记账"，查询时再下传——O(log n)。

📖 三个核心操作

pushup：用子节点更新父节点（修改完子节点后调用）。pushdown：把懒标记下传给子节点（进入子节点前调用）。modify/query：完全包含→直接操作；否则→pushdown→递归→pushup。

操作复杂度说明
build()O(n)建树，从根递归构造
modify(l,r,v)O(log n)区间修改+懒标记
query(l,r)O(log n)区间查询，路过时 pushdown
空间复杂度O(4n)必须开 4 倍数组！
C++
typedef long long ll;
const int N = 1e5 + 5;
struct Node { int l, r; ll sum, add; } tr[N * 4]; // 4倍！
int a[N];

void pushup(int u) { tr[u].sum = tr[u<<1].sum + tr[u<<1|1].sum; }

void pushdown(int u) {  // 懒标记下传
    auto &rt = tr[u], &L = tr[u<<1], &R = tr[u<<1|1];
    if (rt.add) {
        L.add += rt.add; L.sum += (L.r - L.l + 1) * rt.add;
        R.add += rt.add; R.sum += (R.r - R.l + 1) * rt.add;
        rt.add = 0;  // 清空当前标记
    }
}
void build(int u, int l, int r) {
    tr[u] = {l, r};
    if (l == r) { tr[u].sum = a[l]; return; }
    int mid = (l + r) >> 1;
    build(u<<1, l, mid); build(u<<1|1, mid+1, r);
    pushup(u);
}
void modify(int u, int l, int r, int v) {
    if (tr[u].l >= l && tr[u].r <= r) {  // 完全包含
        tr[u].sum += (tr[u].r - tr[u].l + 1) * v;
        tr[u].add += v; return;  // 打标记，不往下
    }
    pushdown(u);  // 进入子节点前必须下传！
    int mid = (tr[u].l + tr[u].r) >> 1;
    if (l <= mid) modify(u<<1, l, r, v);
    if (r > mid) modify(u<<1|1, l, r, v);
    pushup(u);
}
ll query(int u, int l, int r) {
    if (tr[u].l >= l && tr[u].r <= r) return tr[u].sum;
    pushdown(u);
    int mid = (tr[u].l + tr[u].r) >> 1; ll res = 0;
    if (l <= mid) res += query(u<<1, l, r);
    if (r > mid) res += query(u<<1|1, l, r);
    return res;
}
⚠️ 三大易错： ① 开 4 倍空间！② 进入子节点前必须 pushdown！③ 从子节点返回后必须 pushup！这三个缺一个就错。

字典树 (Trie)

进阶

💡 什么是 Trie？

又称前缀树，用于大量字符串的高效检索。每个节点有 26 个子节点（对应 a-z）。从根到某节点的路径就是一个字符串。插入/查询 O(L)，L 为字符串长度，与数据总量无关。

📖 01-Trie：求最大异或

每个节点只有 0/1 两条边。将数字二进制拆分（32位）插入 Trie。查询最大异或时优先走相反位——因为异或相同=0、不同=1，高位相反贡献更大。O(n×32)。

操作复杂度说明
insert(s)O(L)逐字符走 Trie 树，L=字符串长度
query(s)O(L)查询 s 是否出现过 / 出现次数
01-Trie 插入O(32)数字拆成二进制逐位插入
01-Trie 最大异或O(32)每位优先走相反位
C++
// ===== 字典树 =====
const int N = 1e5 + 5;  // 总字符数
int son[N][26], cnt[N], idx = 0;
// son[p][c] = 节点 p 经过字符 c 到达的子节点

void insert(string& s) {
    int p = 0;  // 从根开始
    for (char c : s) {
        int u = c - 'a';
        if (!son[p][u]) son[p][u] = ++idx;  // 创建新节点
        p = son[p][u];
    }
    cnt[p]++;  // 以该节点结尾的单词数+1
}
int query(string& s) {  // 查询 s 出现次数
    int p = 0;
    for (char c : s) {
        int u = c - 'a';
        if (!son[p][u]) return 0;  // 不存在
        p = son[p][u];
    }
    return cnt[p];
}

// ===== 01-Trie：求数组中两个数的最大异或值 =====
const int M = N * 31;  // 每个数最多31位
int son2[M][2], idx2 = 0;
void insert(int x) {
    int p = 0;
    for (int i = 30; i >= 0; i--) {  // 从高位到低位
        int u = (x >> i) & 1;
        if (!son2[p][u]) son2[p][u] = ++idx2;
        p = son2[p][u];
    }
}
int maxXor(int x) {  // 查询与 x 异或的最大值
    int p = 0, res = 0;
    for (int i = 30; i >= 0; i--) {
        int u = (x >> i) & 1;
        // 优先走相反位（异或=1 贡献大）
        if (son2[p][!u]) { res |= (1 << i); p = son2[p][!u]; }
        else p = son2[p][u];
    }
    return res;
}
🏆 理解关键： Trie 用空间换时间，把字符串公共前缀合并存储。01-Trie 的"优先走相反位"是贪心思想——高位差异越大异或值越大。

图的存储

基础

💡 图是什么？

图由顶点和边组成——社交网络、交通路网、依赖关系都是图。三种存储方式各有适用场景：邻接矩阵（稠密图）、邻接表（最常用）、链式前向星（最快）。

📖 链式前向星原理

每条边有唯一编号 idx。h[u] 存 u 的最后一条边的编号，ne[i] 串起前面的边。遍历 u 的边：for(i=h[u]; ~i; i=ne[i])。本质是数组模拟的邻接表，比 vector 更快更省内存。

操作复杂度说明
邻接表 vectorO(V+E) 空间最常用，灵活方便
链式前向星O(V+E) 空间最快，边有编号，卡常必备
邻接矩阵O(V²) 空间n≤2000 稠密图，Floyd 用
Floyd 多源最短路O(V³)配合邻接矩阵使用
C++
// ===== 1. 邻接表 — 最常用 =====
vector> g(n + 1);
// 加边
g[u].push_back(v);          // 有向边
g[u].push_back(v); g[v].push_back(u); // 无向边
// 带权边
vector>> gw(n + 1);
gw[u].push_back({v, w});

// ===== 2. 链式前向星 — 最快 =====
const int N = 1e5+5, M = 2e5+5;
int h[N], e[M], ne[M], w[M], idx;
memset(h, -1, sizeof h);  // -1 表示空
void add(int u, int v, int wt) {  // 加边 u→v 权 wt
    e[idx] = v; w[idx] = wt;
    ne[idx] = h[u]; h[u] = idx++;
}
// 遍历 u 的所有出边
for (int i = h[u]; i != -1; i = ne[i]) {
    int v = e[i], weight = w[i];  // 邻接点v，边权weight
}

// ===== 3. 邻接矩阵 =====
int g2[1005][1005];
memset(g2, 0x3f, sizeof g2);  // 初始化为无穷大
for (int i = 1; i <= n; i++) g2[i][i] = 0;
g2[u][v] = min(g2[u][v], w);  // 加边
🏆 选择建议： 日常刷题用 vector 邻接表（最简单）。需要卡常优化时换链式前向星。n≤500 的稠密图用邻接矩阵。
