vector — 动态数组

#include <vector>

🔬 底层实现

连续内存存储的动态数组。当元素数量超过当前容量时，会重新分配一块更大的内存（通常 1.5x 或 2x 增长），将旧元素拷贝/移动到新空间。这意味着大部分操作在末尾完成，中间插入/删除需要移动元素。

💡 竞赛要点

竞赛中最常用的容器，没有之一。绝大多数情况用 vector 就够了。注意 reserve() 预分配空间可以避免反复扩容，shrink_to_fit() 可以释放多余容量。

操作时间复杂度说明
push_back()O(1) 均摊末尾插入；扩容时 O(n)
pop_back()O(1)删除末尾元素
operator[]O(1)随机访问，不检查越界
at()O(1)随机访问，检查越界（抛异常）
insert(it, val)O(n)在迭代器位置插入，后续元素后移
erase(it)O(n)删除迭代器位置元素，后续元素前移
front() / back()O(1)获取首/尾元素引用
size() / empty()O(1)获取大小/判空
clear()O(n)清空（析构每个元素）
reserve(n)O(n)预分配至少 n 个元素的空间
C++
#include <vector>
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    // === 初始化 ===
    vector<int> a;                    // 空 vector
    vector<int> b(10);               // 10 个默认值 0
    vector<int> c(10, -1);           // 10 个 -1
    vector<int> d = {1, 2, 3, 4, 5};// 列表初始化 (C++11)
    vector<int> e(d.begin(), d.begin() + 3); // 从迭代器构造: {1,2,3}

    // === 常用操作 ===
    a.push_back(42);                 // 末尾插入
    a.pop_back();                    // 末尾删除
    int x = a[0];                    // 随机访问（不检查越界，竞赛中直接用）
    a.reserve(100000);               // 预分配空间，避免频繁扩容

    // === 遍历 ===
    for (int i = 0; i < (int)a.size(); i++) { /* a[i] */ }
    for (int v : a) { /* v */ }              // 范围 for (C++11)
    for (auto it = a.begin(); it != a.end(); ++it) { /* *it */ }

    // === 常用算法 ===
    sort(a.begin(), a.end());                     // 升序排序 O(n log n)
    sort(a.rbegin(), a.rend());                   // 降序排序
    reverse(a.begin(), a.end());                  // 翻转 O(n)
    a.erase(unique(a.begin(), a.end()), a.end()); // 去重（先排序）
    auto it = lower_bound(a.begin(), a.end(), x); // 二分查找第一个 ≥x 的位置 O(log n)
    auto it = upper_bound(a.begin(), a.end(), x); // 二分查找第一个 >x 的位置

    // === 二维 vector ===
    int n = 100, m = 200;
    vector<vector<int>> mat(n, vector<int>(m, 0)); // n×m 矩阵

    // === 邻接表 (图论常用) ===
    vector<vector<int>> g(n + 1);  // n 个顶点
    g[u].push_back(v);               // 添加有向边
    g[u].push_back(v); g[v].push_back(u); // 无向边
}
🏆 竞赛技巧： 使用 reserve() 预分配空间可以显著提升性能。当你知道大概需要 10^5 个元素时，在循环前 v.reserve(100000) 可以避免数十次内存重分配。对于二维 vector，访问 v[i][j] 比 vector<vector<int>> 更快的方式是用一维数组模拟：v[i * cols + j]。

deque — 双端队列

#include <deque>

🔬 底层实现

分段连续存储（一块中控器 + 多个固定大小的缓冲区）。不像 vector 那样是严格的连续内存，但支持在头部和尾部都有 O(1) 的插入删除。随机访问也是 O(1)，但常数比 vector 略大。

💡 竞赛要点

需要双端操作时才用 deque，否则用 vector。常用于滑动窗口的单调队列。内存开销比 vector 大，元素分散存储导致缓存不友好。

操作时间复杂度说明
push_back() / push_front()O(1)尾/头插入
pop_back() / pop_front()O(1)尾/头删除
operator[]O(1)随机访问（常数比 vector 大）
insert(it, val)O(n)中间插入
C++
#include <deque>
#include <vector>
using namespace std;

// 滑动窗口最小值 (单调递增队列)
vector<int> slidingWindowMin(vector<int>& a, int k) {
    deque<int> dq;  // 存下标
    vector<int> res;
    for (int i = 0; i < (int)a.size(); i++) {
        // 弹出队首超出窗口的元素
        while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        // 弹出队尾比当前元素大的（维护单调递增）
        while (!dq.empty() && a[dq.back()] >= a[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) res.push_back(a[dq.front()]);
    }
    return res;
}
// 求最大值只需改成 a[dq.back()] <= a[i]，维护单调递减
🏆 竞赛技巧： deque 最经典的应用是单调队列优化 DP（如多重背包）、滑动窗口最值。0-1 BFS 中 deque 用于 O(V+E) 求边权为 0 或 1 的最短路：0 权边 push_front，1 权边 push_back。

list / forward_list — 链表

#include <list>

🔬 底层实现

双向链表（list）或单向链表（forward_list）。元素在内存中不连续存储，每个节点包含数据 + 指针。插入/删除 O(1)，但无法随机访问，只能顺序遍历。forward_list 更省内存，但只能单向移动。

💡 竞赛要点

竞赛中极少直接使用 list。原因：缓存不友好，常数大，没有 operator[]。需要链表场景（如邻接表、LRU）通常用 vector 或手写静态链表（数组模拟）替代，速度更快且内存更紧凑。

操作时间复杂度说明
push_back() / push_front()O(1)尾/头插入
insert(it, val)O(1)在迭代器位置插入（不需要移动元素！）
erase(it)O(1)删除迭代器位置元素
splice()O(1)将另一个 list 的元素转移过来（指针重定向）
sort()O(n log n)list 有自己专属的 sort 成员函数
⚠️ 重要注意： 不要对 list 使用 std::sort()！list 只能用自己的成员函数 lst.sort()，因为 std::sort 需要随机访问迭代器。同样，lst.unique() 和 lst.merge() 也是成员函数。竞赛中大多数"链表题"用数组模拟静态链表即可。

stack — 栈

#include <stack>

🔬 底层实现

stack 是容器适配器，不是独立容器。默认底层用 deque 实现，也可以指定 vector 或 list。只暴露栈顶操作（LIFO），隐藏了底层容器的其他接口。

💡 竞赛要点

常用于 DFS 非递归实现、括号匹配、单调栈（求下一个更大元素）、表达式求值。竞赛中很多人直接用 vector + push_back()/pop_back() 模拟栈，因为还能访问历史元素，调试更方便。

操作时间复杂度说明
push(x)O(1)压栈
pop()O(1)弹栈（不返回值）
top()O(1)返回栈顶引用（不弹出）
C++
#include <vector>
#include <stack>
using namespace std;

// 找每个元素右边第一个比它大的元素（单调递减栈）
vector<int> nextGreater(vector<int>& a) {
    int n = a.size();
    vector<int> res(n, -1);
    stack<int> st;  // 存下标
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            res[st.top()] = i;  // 或 a[i]
            st.pop();
        }
        st.push(i);
    }
    return res;
}

// 求最大矩形面积（直方图）也是单调栈经典应用

queue — 队列

#include <queue>

🔬 底层实现

queue 也是容器适配器，默认底层用 deque。只暴露队首队尾操作（FIFO）。BFS 的标准工具。

💡 竞赛要点

BFS 标配。注意 pop() 不返回值，要先 front() 再 pop()。queue 没有 clear() 方法，快速清空可以用 queue<int>().swap(q) 或直接用空队列替换。

操作时间复杂度说明
push(x)O(1)入队
pop()O(1)出队（不返回值）
front() / back()O(1)队首/队尾引用
C++
#include <queue>
#include <vector>
using namespace std;

// 邻接表 BFS
void bfs(int start, vector<vector<int>>& g) {
    int n = g.size();
    vector<bool> vis(n);
    queue<int> q;
    q.push(start);
    vis[start] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        // 处理 u
        for (int v : g[u]) {
            if (!vis[v]) {
                vis[v] = true;
                q.push(v);
            }
        }
    }
}

// BFS 求最短路（边权为1）
vector<int> bfsDist(int start, vector<vector<int>>& g) {
    int n = g.size();
    vector<int> dist(n, -1);
    queue<int> q;
    dist[start] = 0; q.push(start);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return dist;
}

priority_queue — 优先队列（堆）

#include <queue>

🔬 底层实现

默认用 vector + 二叉大根堆（make_heap/push_heap/pop_heap）。默认是大根堆（top 返回最大值）。要小根堆需要用 greater<T> 比较器。

💡 竞赛要点

Dijkstra 最短路、Prim 最小生成树、贪心、Top-K 问题的核心数据结构。没有迭代器，只能访问堆顶。要遍历所有元素可以用底层容器，但顺序不是有序的。支持自定义比较器来定义优先级。

操作时间复杂度说明
push(x)O(log n)插入元素并调整堆
pop()O(log n)删除堆顶
top()O(1)返回堆顶引用（不可修改）
C++
#include <queue>
#include <vector>
using namespace std;
typedef long long ll;
typedef pair<ll, int> pli;  // {距离, 节点}

// Dijkstra 最短路（小根堆）
vector<ll> dijkstra(int s, vector<vector<pair<int,ll>>>& g) {
    int n = g.size();
    vector<ll> dist(n, 1e18);
    // 用小根堆：greater 比较器，或存负距离
    priority_queue<pli, vector<pli>, greater<pli>> pq;
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d != dist[u]) continue;  // 惰性删除
        for (auto [v, w] : g[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}

// ===== 自定义比较器 =====
// 方法1: struct + operator()
struct Cmp {
    bool operator()(const pair<int,int>& a, const pair<int,int>& b) {
        return a.second < b.second;  // 按 second 降序（大根堆行为）
    }
};
priority_queue<pair<int,int>, vector<pair<int,int>>, Cmp> pq;

// 方法2: lambda (C++11)
auto cmp = [](int a, int b) { return a > b; };  // > 得到小根堆
priority_queue<int, vector<int>, decltype(cmp)> pq(cmp);

// 方法3: 简单小根堆技巧 — 存负数
priority_queue<int> pq;
pq.push(-x);  // 取出来再取负
🏆 竞赛技巧： priority_queue 不能遍历，也不能直接修改中间元素的优先级。需要修改时用"惰性删除"：push 新值，pop 时判断是否与当前最优值一致。对顶堆（两个堆维护中位数）也是经典技巧。

set / multiset — 有序集合

#include <set>

🔬 底层实现

红黑树（平衡二叉搜索树）。元素按值自动排序。set 不允许重复元素，multiset 允许重复。插入、删除、查找都是 O(log n)。

💡 竞赛要点

需要动态维护有序序列时使用。常用于需要找前驱后继、二分查找的场景。注意 set 的迭代器是双向的（不像 vector 可以 it+n），只能 ++/--。multiset 的 erase 若传值会删除所有等于该值的元素，只删一个要用 erase(find(x))。

操作时间复杂度说明
insert(x)O(log n)插入元素
erase(x)O(log n)删除元素（传值/迭代器）
find(x)O(log n)查找元素，返回迭代器
count(x)O(log n + k)对于 multiset 返回出现次数
lower_bound(x)O(log n)第一个 ≥x 的位置
upper_bound(x)O(log n)第一个 >x 的位置
C++
#include <set>
#include <iostream>
using namespace std;

int main() {
    set<int> s;
    s.insert(3); s.insert(1); s.insert(4); s.insert(1);
    // s = {1, 3, 4}  重复的 1 被忽略

    // 遍历：自动按升序
    for (int x : s) cout << x << " ";  // 1 3 4

    // 查找
    auto it = s.find(3);
    if (it != s.end()) cout << "Found: " << *it;

    // 二分
    auto lb = s.lower_bound(2);  // 指向 3（第一个 ≥2）
    auto ub = s.upper_bound(3);  // 指向 4（第一个 >3）

    // 查找前驱后继（注意边界）
    auto it = s.find(3);
    if (it != s.begin()) { auto prev = prev(it); /* 前驱 */ }
    if (next(it) != s.end()) { auto nxt = next(it); /* 后继 */ }

    // ===== multiset =====
    multiset<int> ms;
    ms.insert(1); ms.insert(1); ms.insert(2);
    ms.erase(1);           // 删除所有 1！危险！
    ms.erase(ms.find(1));  // 只删一个 1（先 find 再 erase）
    ms.extract(1);         // C++17 更高效的方式

    // 降序 set
    set<int, greater<int>> s2;
}
⚠️ 常见陷阱： multiset 的 ms.erase(val) 会删除所有值为 val 的元素！只删一个要写 ms.erase(ms.find(val))。另外 count() 在 multiset 中是 O(k + log n)（k 是出现次数），不是 O(log n)。

map / multimap — 有序映射

#include <map>

🔬 底层实现

也是红黑树。存储键值对，按键自动排序。map 键唯一，multimap 允许重复键。插入、删除、查找 O(log n)。

💡 竞赛要点

需要按键有序遍历时用 map，否则用 unordered_map 更快。map 的 operator[] 很特殊：如果键不存在会自动插入默认值，所以查询前最好用 find() 或 count() 判断。C++17 的 insert_or_assign 和结构化绑定 auto [it, ok] = m.insert({k, v}) 很好用。

操作时间复杂度说明
operator[]O(log n)访问/插入，键不存在时自动创建
insert({k,v})O(log n)插入键值对
erase(k)O(log n)删除键
find(k)O(log n)查找键
count(k)O(log n)判断键是否存在（0 或 1）
C++
#include <map>
#include <iostream>
using namespace std;

int main() {
    map<string, int> mp;

    // 插入
    mp["Alice"] = 90;           // 方式1：直接赋值
    mp.insert({"Bob", 85});     // 方式2：insert
    mp.emplace("Carol", 95);    // 方式3：emplace (C++11 就地构造)

    // 检查键是否存在
    if (mp.count("Alice")) { /* 存在 */ }
    if (mp.find("Bob") != mp.end()) { /* 存在 */ }

    // 安全访问（不会自动插入不存在的键）
    auto it = mp.find("Dave");
    if (it != mp.end()) cout << it->second;

    // 遍历：按键的字典序升序
    for (auto& [name, score] : mp)  // C++17 结构化绑定
        cout << name << ": " << score << '\n';

    // 插入并检查是否成功
    auto [iter, inserted] = mp.insert({"Eve", 88});
    if (inserted) { /* 插入成功 */ }

    // lower_bound / upper_bound（与 set 相同）
    auto lb = mp.lower_bound("B");  // 第一个 ≥ "B" 的键

    // 离散化技巧（竞赛常用！）
    vector<int> raw = {100, 5, 200, 5, 100};
    // 去重排序后映射到 0,1,2...
    sort(raw.begin(), raw.end());
    raw.erase(unique(raw.begin(), raw.end()), raw.end());
    // raw = {5, 100, 200}, 5→0, 100→1, 200→2
    int id = lower_bound(raw.begin(), raw.end(), val) - raw.begin();
}
🏆 竞赛技巧： map 常用于离散化（将大范围值映射到小范围下标），但直接用 sort+unique+lower_bound 比 map 更快。map 的遍历是有序的，如果需要按插入顺序则不行。C++17 的结构化绑定 for (auto& [k, v] : mp) 让遍历非常简洁。

unordered_set / unordered_map — 哈希表

#include <unordered_set> | <unordered_map>

🔬 底层实现

哈希表（拉链法）。元素无序存储。平均 O(1) 的插入、删除、查找。但最坏情况可能退化到 O(n)（哈希碰撞严重时）。不支持 lower_bound/upper_bound。

💡 竞赛要点

不需要有序时优先用 unordered 版本，常数比有序版本小很多。但竞赛中有时会被卡哈希（构造大量碰撞），可以自定义哈希函数或使用 gp_hash_table（pb_ds）。C++11 有了 unordered_map，但很多选手仍用 __gnu_pbds::gp_hash_table 防卡。

C++
#include <unordered_map>
#include <unordered_set>
using namespace std;

// === 防卡哈希：让标准哈希不可预测 ===
struct custom_hash {
    static uint64_t splitmix64(uint64_t x) {
        x += 0x9e3779b97f4a7c15;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9;
        x = (x ^ (x >> 27)) * 0x94d049bb133111eb;
        return x ^ (x >> 31);
    }
    size_t operator()(uint64_t x) const {
        static const uint64_t FIXED_RANDOM =
            chrono::steady_clock::now().time_since_epoch().count();
        return splitmix64(x + FIXED_RANDOM);
    }
    // 对 pair 的哈希
    size_t operator()(pair<int,int> p) const {
        return (*this)(((uint64_t)p.first << 32) | p.second);
    }
};

unordered_map<int, int, custom_hash> safe_mp;
unordered_set<int, custom_hash> safe_set;

// === C++11 pair 哈希（标准库不提供，需自己写） ===
struct pair_hash {
    template<class T1, class T2>
    size_t operator()(const pair<T1,T2>& p) const {
        return hash<T1>()(p.first) ^ (hash<T2>()(p.second) << 1);
    }
};
unordered_map<pair<int,int>, int, pair_hash> pair_mp;
⚠️ 防卡重要： Codeforces 等平台上有时会有人故意构造数据让 unordered_map 退化到 O(n) 导致 TLE。可以使用上面的 custom_hash，或者直接用 map（稳定 O(log n)），或者在 C++20 中用 std::flat_map。对于整数键，pb_ds 的 gp_hash_table 也是很好的选择。

bitset — 位集

#include <bitset>

🔬 底层实现

用 unsigned long 数组压缩存储每一位，每个 bit 占 1 位（而非 bool 的 1 字节）。大小在编译时确定（模板参数），所有位运算被编译为高效的字运算。空间是 bool 数组的 1/8，时间效率也极高。

💡 竞赛要点

超大杀器！ 对于 n ≤ 10^5 左右的布尔运算，bitset 的位运算可以将复杂度除以 32 或 64。常用于：优化可达性 DP（传递闭包 O(n³/w)）、01 背包存在性判定、筛法标记。C++ 中 bitset 最遗憾的一点是大小必须编译期确定。

操作时间复杂度说明
set() / reset() / flip()O(n / w)w = 32 或 64（字长）
operator[]O(1)访问某一位
&, |, ^, ~O(n / w)按位与/或/异或/非
<<, >>O(n / w)左移/右移
count()O(n / w)统计 1 的个数
_Find_first()O(n / w)第一个 1 的位置（GCC 扩展）
_Find_next(i)O(n / w)i 之后第一个 1 的位置
C++
#include <bitset>
#include <iostream>
using namespace std;

const int N = 2005;
bitset<N> g[N];  // g[i][j] 表示 i 可达 j

// 传递闭包 O(n³ / 64)
void transitiveClosure(int n) {
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            if (g[i][k])           // 如果 i 可达 k
                g[i] |= g[k];      // 则 i 可达 k 能到达的所有点
    // 注意：这里 g[i] |= g[k] 是 O(n/64) 的位运算！
    // 比传统 Floyd O(n³) 快约 64 倍
}

// bitset 优化 01 背包可行性
bitset<100005> dp;
dp[0] = 1;
for (int x : items) {
    dp |= dp << x;  // dp[j] = dp[j] | dp[j-x]
}
// dp[i] == 1 表示可以凑出总和 i

// 常用操作
bitset<32> bs(42);     // 用整数初始化
bs.set(3);              // 第 3 位置 1
bs.reset(5);            // 第 5 位置 0
bs.flip(2);             // 第 2 位翻转
bool b = bs[3];         // 读取第 3 位
int cnt = bs.count();   // 1 的个数
bs.to_string();         // 转字符串 "001010..."
bs.to_ullong();         // 转 unsigned long long
int first = bs._Find_first();   // 第一个 1 的位置 (GCC)
int next = bs._Find_next(5);    // 5 之后第一个 1 的位置 (GCC)
🏆 竞赛技巧： bitset 优化的传递闭包（上面的 Floyd 变种）可以处理 n=2000 的图，传统 Floyd O(n³) 只能处理 n≤500。01 背包可行性 DP 也可以用 bitset 一次处理完。另外 _Find_first() 和 _Find_next() 是 GCC 扩展（竞赛环境大多支持），遍历所有 1 的位置比手动检查快。

pb_ds — GNU 扩展数据结构

#include <ext/pb_ds/...>

🔬 底层实现

GNU C++ 扩展库（Policy-Based Data Structures），提供标准库之外的高性能数据结构：哈希表（gp_hash_table，比 unordered_map 快且防卡）、平衡树（tree，支持查第 k 小和排名）、Trie 树等。Codeforces 等平台通常支持。

💡 竞赛要点

竞赛中两大神技：(1) gp_hash_table 替代 unordered_map，不会被卡哈希；(2) ordered_set（tree）可以在 O(log n) 内完成 set 的所有操作 + 查第 k 小 + 查元素排名。注意：洛谷等部分 OJ 不支持 pb_ds。

C++
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>
#include <ext/pb_ds/hash_policy.hpp>
using namespace __gnu_pbds;

// === ordered_set: 支持 find_by_order 和 order_of_key ===
// 本质是红黑树，用法类似 set，但额外支持：
//   - find_by_order(k): 返回第 k 小的迭代器 (0-indexed)  O(log n)
//   - order_of_key(x):  返回 < x 的元素个数 (即排名)    O(log n)
typedef tree<
    int,                      // 键类型
    null_type,                // 无映射值 (set 模式)
    less<int>,                // 比较器
    rb_tree_tag,              // 红黑树
    tree_order_statistics_node_update // 开启排名统计
> ordered_set;

// 使用示例
ordered_set os;
os.insert(5); os.insert(2); os.insert(8); os.insert(3);
// os = {2, 3, 5, 8}
cout << *os.find_by_order(2);        // 5 (第 2 小，0-indexed)
cout << os.order_of_key(6);           // 3 (有 3 个数 < 6: 2,3,5)

// === 多重集版本（允许重复元素）===
typedef tree<
    pair<int,int>,  // {值, 唯一ID} 来区分重复元素
    null_type,
    less<pair<int,int>>,
    rb_tree_tag,
    tree_order_statistics_node_update
> ordered_multiset;

// === gp_hash_table: 比 unordered_map 更快更安全 ===
#include <ext/pb_ds/assoc_container.hpp>
using namespace __gnu_pbds;
gp_hash_table<int, int> mp;  // 替代 unordered_map，防卡哈希！

// 链地址法哈希表（标准拉链）
cc_hash_table<int, int> mp2;
操作ordered_setgp_hash_table
insert / erase / findO(log n)O(1) 均摊
find_by_order(k)O(log n)不支持
order_of_key(x)O(log n)不支持
lower_bound / upper_boundO(log n)不支持
🏆 竞赛技巧： order_of_key() 可以轻松求逆序对（遍历 + 查询比当前数大的个数）。find_by_order() 可用于动态维护中位数。如果题目需要同时支持 set 的去重 + 第 k 小查询，ordered_set 是最快的选择，比手写 Treap/Splay 方便得多。
⚠️ 注意： pb_ds 是 GCC 专属扩展，洛谷 / 牛客等国内 OJ 大多不支持！Codeforces / AtCoder 支持。提交前确认平台编译器。另外 tree_order_statistics_node_update 不支持多重集，需要配合 pair 使用。

pair / tuple — 打包多个值

#include <utility> | <tuple>

🔬 底层实现

pair 是两个值的简单结构体（first + second），tuple 可以存储任意数量的任意类型值。它们都支持比较运算符（按字典序），可以直接用于容器排序和作为 map 的键。

💡 竞赛要点

pair 极其常用：priority_queue 的 Dijkstra（pair<距离, 节点>）、map 的键（pair<int,int> 代替二维坐标）。tuple 主要用于需要返回多个值或临时打包少量数据时。C++17 结构化绑定让 pair/tuple 的使用体验提升巨大。

C++
#include <utility>
#include <tuple>
#include <iostream>
using namespace std;

int main() {
    // === pair ===
    pair<int, double> p1(1, 3.14);
    auto p2 = make_pair(2, 2.718);
    pair p3 = {3, 1.414};  // C++17 CTAD

    cout << p1.first << " " << p1.second;

    // 结构化绑定 (C++17)
    auto [a, b] = p1;

    // pair 的比较：先比 first，再比 second
    // 非常适合放进 set / map / priority_queue

    // === tuple ===
    tuple<int, string, double> t1(1, "hello", 3.14);
    auto t2 = make_tuple(2, "world", 2.718);
    tuple t3 = {3, "!", 1.414};  // C++17

    // 访问 tuple 元素
    cout << get<0>(t1);  // 按位置访问
    cout << get<int>(t1);  // 按类型访问（如果唯一）

    // 结构化绑定
    auto [x, s, d] = t1;

    // tie 用于解包和比较
    int x, y; tie(x, y) = p1;
    // tie 常用于自定义结构体的比较运算符
}

// === 竞赛中最常见的 pair 用法 ===

// 1. Dijkstra
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;

// 2. 点坐标或区间
vector<pair<int,int>> intervals;
sort(intervals.begin(), intervals.end());  // 按左端点排序

// 3. 带索引的排序（稳定排序等价）
vector<pair<int,int>> arr;  // {值, 原始下标}
sort(arr.begin(), arr.end());

string — 字符串

#include <string>

🔬 底层实现

类似 vector<char> 但针对字符串做了优化。现代实现大多使用 SSO（Small String Optimization）：短字符串直接存在栈上（不分配堆内存），长字符串才用堆。支持 + 拼接、比较运算符、substr、find 等丰富操作。

💡 竞赛要点

比 C 风格字符串安全方便得多。注意 substr(pos, len) 是 O(len) 的（会复制），频繁取子串可能很慢。大量字符串拼接时用 += 比 + 高效，或者用 ostringstream。

操作时间复杂度说明
operator[]O(1)随机访问字符
push_back(c)O(1) 均摊末尾追加字符
+= / append()O(m) 均摊追加字符串，m 为追加长度
substr(pos, len)O(len)截取子串（会复制！）
find(s) / rfind(s)O(n·m)查找子串（朴素算法，非 KMP）
compare(s)O(min(n,m))字典序比较
to_string(x)O(位数)数值转字符串
stoi() / stoll()O(位数)字符串转数值
C++
#include <string>
#include <iostream>
using namespace std;

int main() {
    string s = "Hello";
    string t = "World";

    // 拼接
    string u = s + " " + t;   // "Hello World"
    s += "!!";                 // "Hello!!"
    s.push_back('~');          // "Hello!!~"

    // 子串
    string sub = s.substr(1, 3);   // "ell" (从位置1开始，长度3)
    string sub2 = s.substr(2);     // "llo!!~" (从位置2到末尾)

    // 查找
    size_t pos = s.find("ll");     // 2 (npos 表示未找到)
    if (s.find("xy") == string::npos) { /* 未找到 */ }
    pos = s.rfind('l');            // 3 (反向查找)

    // 比较（直接用运算符）
    if (s == t) { }
    if (s < t) { }  // 字典序比较

    // 类型转换 (C++11)
    string num = to_string(42);        // "42"
    string dbl = to_string(3.14159);   // "3.141590"
    int x = stoi("42");                // 42
    long long y = stoll("123456789");
    double z = stod("3.14");

    // 常用操作
    s.empty();      // 判空
    s.size();       // 长度（同 length()）
    s.clear();      // 清空
    s.resize(10);   // 调整大小
    s.front();      // 首字符引用
    s.back();       // 尾字符引用
    reverse(s.begin(), s.end());  // 翻转

    // 整行读取
    string line;
    getline(cin, line);  // 读一行
}
⚠️ 注意： string::find() 不是 KMP，复杂度 O(n·m)，在最坏情况下可能很慢。如果需要多次高效子串匹配，请使用 KMP 或 AC 自动机。substr() 每次都复制，字符串哈希等场景建议传位置参数而不是截子串。

常用算法函数库

#include <algorithm> | <numeric>

🔬 排序相关

sort() 使用 Introsort（快排 + 堆排 + 插入排序混合），O(n log n)，不稳定排序。stable_sort() 是归并排序，稳定但略慢或需要额外内存。nth_element() 使用快速选择，O(n) 将第 k 小放到正确位置。

🔬 二分查找

lower_bound() 返回第一个 ≥x 的迭代器，upper_bound() 返回第一个 >x 的迭代器，binary_search() 判断是否含有 x，equal_range() 返回等于 x 的区间。都需要有序序列。

C++
#include <algorithm>
#include <numeric>
using namespace std;

// ===== 排序 =====
sort(a.begin(), a.end());                    // 升序
sort(a.begin(), a.end(), greater<int>()); // 降序
sort(a.begin(), a.end(), [](int x, int y) { return x > y; }); // 自定义
stable_sort(a.begin(), a.end());             // 稳定排序

// ===== 二分（需要有序）=====
int idx = lower_bound(a.begin(), a.end(), x) - a.begin(); // 第一个 ≥x
int idx = upper_bound(a.begin(), a.end(), x) - a.begin(); // 第一个 >x
bool ex = binary_search(a.begin(), a.end(), x);           // 是否存在

// ===== 最值 =====
auto it = min_element(a.begin(), a.end());  // 最小值位置
auto it = max_element(a.begin(), a.end());  // 最大值位置
int mn = *min_element(a.begin(), a.end());  // 最小值
pair<auto,auto> p = minmax_element(a.begin(), a.end()); // 同时求

// ===== 修改序列 =====
reverse(a.begin(), a.end());                 // 翻转
rotate(a.begin(), a.begin()+k, a.end());    // 循环左移 k 位
random_shuffle(a.begin(), a.end());         // 随机打乱 (C++14 前)
shuffle(a.begin(), a.end(), mt19937{r});    // C++11 随机打乱
fill(a.begin(), a.end(), 42);               // 全部填充为 42
copy(src.begin(), src.end(), dst.begin());  // 拷贝
iota(a.begin(), a.end(), 0);                // 填充 0,1,2,... (numeric)

// ===== 去重 =====
sort(a.begin(), a.end());
a.erase(unique(a.begin(), a.end()), a.end());  // 去重三部曲

// ===== 堆操作（在 vector 上）=====
make_heap(v.begin(), v.end());               // 建堆
v.push_back(x); push_heap(v.begin(), v.end()); // 插入
pop_heap(v.begin(), v.end()); v.pop_back();    // 删除堆顶

// ===== 排列 =====
next_permutation(a.begin(), a.end());  // 下一个排列
prev_permutation(a.begin(), a.end());  // 上一个排列
// 要获得全排列，先 sort，再 loop next_permutation

// ===== 求和 / 前缀 =====
int sum = accumulate(a.begin(), a.end(), 0);          // 求和
partial_sum(a.begin(), a.end(), pref.begin());        // 前缀和
adjacent_difference(a.begin(), a.end(), diff.begin());// 差分

// ===== 计数 =====
int cnt = count(a.begin(), a.end(), val);   // 统计 val 出现次数
int cnt = count_if(a.begin(), a.end(), [](int x){ return x>0; });
🏆 竞赛技巧： nth_element() 求第 k 小是 O(n)，比全排序快得多。partial_sort() 求前 k 小也是常用操作。next_permutation() 是暴力枚举排列的神器（虽然复杂度是 O(n!)）。iota() 在并查集初始化时非常好用。

竞赛常用宏定义 & 编译优化

#pragma / #define

🔬 为什么用宏

竞赛代码追求简洁高效。宏可以大幅减少重复代码，让你专注于算法本身。配合 #pragma 编译指令可以开启编译器优化、加速 IO。

💡 竞赛要点

一套好用的宏模板能在比赛中节省大量打字时间。最常用的：for 循环简写、#define int long long、快读快写。注意：别用得太花哨，要保证代码可读性。

#define per(i,a,b) for(int i=(b)-1;i>=(a);i--)
#define all(x) (x).begin(),(x).end()
#define sz(x) (int)(x).size()
#define pb push_back
#define fi first

// ===== 快速 IO（必须在使用 cin/cout 前调用）=====

// ===== 常用函数 =====

需求场景推荐容器理由
需要随机访问 + 末尾增删vector默认首选，O(1) 随机访问
需要双端增删dequeO(1) 头尾操作
需要 O(1) 中间插入删除list但无随机访问，竞赛中少用
需要最大/最小值快速获取priority_queueO(log n) 插入，O(1) 取最值
需要有序 + 快速查找set / mapO(log n)，自动排序
只需要快速查找（无序）unordered_set / map均摊 O(1)，但不有序
需要 LIFO（后进先出）stack单调栈、DFS、括号匹配
需要 FIFO（先进先出）queueBFS 标配
大规模布尔运算 / 位压缩bitset空间省 8×，时间省 64×
二维坐标 / 键值对pair<int,int>可放入 set/map
字符串处理string比 char[] 方便安全
固定大小的小数组array<T,N>vector 的栈上版本
🏆 终极建议： 竞赛中 80% 的情况用 vector 就够了。需要有序且动态插入用 set/map，需要哈希用 unordered_map（注意防卡），BFS 用 queue，最短路用 priority_queue。遇到 n≤2000 的布尔 DP 记得考虑 bitset 优化！
